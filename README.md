# Student marks Analyser

A simple python project that calculates student marks,grade,average and pass/fail status.

## Features

-Accepts students name
-Accepts marks for five subjects
-Calculates total marks
-Calculates Average marks
-Assisgn a grade
-Determines Average marks
-Saves student results to a CSV file
